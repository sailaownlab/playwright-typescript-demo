# Playwright TypeScript Automation Framework
A learning project for building a maintainable UI and API automation framework using Playwright and TypeScript.
## Current Features
- UI automation using Playwright
- API automation using Playwright request context
- TypeScript
- GitHub Actions CI
- Separate UI and API test folders
## Project Structure
```text
tests/
  ui/       UI test specifications
  api/      API test specifications
pages/      Page Object Model classes
fixtures/   Custom Playwright fixtures
utils/      Reusable helper functions
data/       Test data
config/     Framework and environment configuration
